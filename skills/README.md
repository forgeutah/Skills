# Skills

Skills are organized by category. Each subdirectory is a category; each
child directory within a category is one distributable skill with a required
`SKILL.md`.

| Category | Directory | Description |
|----------|-----------|-------------|
| General | [`skills/`](skills/) | Meta-skills, skill development, and agent skill tooling |
| DevOps | [`devops/`](devops/) | CI/CD, infrastructure, deployment, platform tooling |
| Design | [`design/`](design/) | UI/UX, design systems, frontend architecture |
| Databases | [`db/`](db/) | SQL, NoSQL, data modeling, migrations |
| Tools | [`tools/`](tools/) | General-purpose development tools and utilities |
