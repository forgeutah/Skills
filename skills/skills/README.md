# General Skills

Skills about skill development, meta-skills, and agent skill tooling.

Add your skill as a subdirectory with a `SKILL.md` and `evals/evals.json`.

| Skill | What it does |
|-------|---------------|
| [`contribute-via-gh-cli`](contribute-via-gh-cli/) | Fork a repo and open a pull request entirely with `gh`, for repos where you don't have push access. |
